# docs — 文档资料

存放论文与答辩相关的全部文字与图表材料。代码与实验脚本不放在这里。

## 目录规划

| 位置 | 内容 |
|---|---|
| `docs/thesis/` | 论文正文各章节、参考文献库（`.bib` 或 EndNote） |
| `docs/figures/` | 论文插图源文件（drawio / Visio / SVG）与导出图 |
| `docs/logs/` | 指导记录（1–5）、周报、与导师的修改意见汇总 |
| `docs/defense/` | 开题 PPT、中期检查材料、答辩 PPT |
| `docs/dataset/` | 数据集说明、标注规范、标注一致性检验记录 |

## 命名约定

- 论文稿件：`thesis-v{主}.{次}-{日期}.docx`，例如 `thesis-v0.3-20270301.docx`
- 插图：`fig{章号}-{序号}-{简述}.png`，例如 `fig3-02-system-arch.png`
- 指导记录：`guide-{序号}-{日期}.md`
- 只提交 `.md` / `.docx` / `.pdf` / 图片源文件；导出的大体积视频走外部链接
