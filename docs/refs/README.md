## 与课题的贴合度评估

**直接支撑实现的三篇**：[8] 是唯一在 ESP32-S3 上做音频识别的同平台工作，[10] 是唯一把 CNN 单词识别放到单片机上的工作，[1] 是唯一讲电子纸驱动波形与残影的文献。这三篇决定了本课题"能不能做出来"。

**提供方法参照的三篇**：[4][5][6] 都是发音评价，但都在 PC 侧、模型较大、以句子或音素为单位；本课题是**单词级二分类**，可直接借鉴的是特征选择与标注方式，不是网络结构。

**偏弱的**：[7] 是句子级翻译评分，关注语义、流利度与翻译质量，与"单词语音是否读对"关系较远，引用它主要是说明"自动评价可综合多类特征"这一论点。若篇幅紧张可替换。

## 建议补充的文献方向

现有 10 篇在以下两点上偏薄，写作时容易被问：

1. **GOP（Goodness of Pronunciation）系列**——发音评价的经典路线，从置信度到 posterior 打分，是"规则法 vs 模型法"对照的理论背景，目前一篇都没有。
2. **TFLite Micro / ESP-DL 在 ESP32-S3 上的实测报告**——[8][10] 分别用知识蒸馏与 CNN，但没有覆盖 int8 量化后的精度损失与内存占用数据，而这正是本课题 [#4](https://github.com/kyhx/edge-ai-eink-wordbook/issues/4) 的核心。

- 文件名格式：`[编号]-来源-年份-简述.pdf`，编号与开题报告参考文献一致。
- PDF 不入库；如需长期保存或与导师共享，另存网盘并在 `docs/dataset/` 或本文件登记。
- 引用时以开题报告中的 DOI / 页码为准，不以本目录文件为准。
