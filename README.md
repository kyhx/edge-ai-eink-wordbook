## 一、项目简介

本项目设计并实现一款**便携式墨水屏英语单词学习机**。设备以带 PSRAM 的 ESP32-S3 为主控，把单词卡片、发音播放、跟读评价和分级复习整合到一台低干扰、可离线使用的终端上。

核心特点是在**端侧完成发音评价**：采集真实跟读语音并人工标注，训练轻量二分类模型，量化后部署到单片机；同时设计基于基频的规则法作为对照，比较两种方法在准确率、与人工标注的一致程度和推理耗时上的差异。

电子墨水屏采用反射式显示与双稳态保持，静态画面不耗电，适合以文字为主的长时间学习场景；整机在无网络条件下也能完成"看词—听音—跟读—反馈—复习"的闭环。

> 说明：本系统仅对词库内单词的跟读给出"正确 / 需要改进"的提示，结果仅供学习参考，不作为英语语言能力评定依据。

## 二、主要功能

| 模块 | 功能 | 说明 |
|---|---|---|
| 单词卡 | 词条显示、翻页、释义与例句 | 建立不少于 50 个词条的英语词库 |
| 发音播放 | 单词标准音播放 | 音频功放 + 扬声器/耳机输出 |
| 跟读评价 | 录音 → 特征提取 → 本地推理 → 反馈 | 二分类：发音正确 / 需要改进 |
| 分级复习 | 按掌握程度安排复习 | 参考间隔重复策略，管理每日任务 |
| 数据同步 | 学习记录无线同步 | Wi-Fi 上传学习进度与评价结果 |
| 功耗管理 | 待机、录音、推理状态切换 | 墨水屏局部刷新以降低整机功耗 |

## 三、技术路线

```
┌────────────────────────────── 设备端（ESP32-S3） ──────────────────────────────┐
│  按键/触摸 ──► 主控状态机 ──► 墨水屏驱动（全刷 / 局部刷新 / 残影处理）          │
│                    │                                                          │
│                    ├─► 词库与复习调度（间隔重复）                               │
│                    ├─► 音频播放（I2S + 功放）                                   │
│                    └─► 录音（I2S 麦克风）──► MFCC / 梅尔频谱 ──► 量化模型推理   │
│                                                          └──► 规则法（基频）    │
└───────────────────────────────────────────────────────────────────────────────┘
                                   ▲
                                   │ Wi-Fi 同步学习记录
                                   ▼
                       上位机 / 服务器（可选）

离线训练侧（PC）：
语音采集与标注 → 特征提取 → 轻量模型训练 → 量化 → 导出 → 固件集成
```

**研究方法**

1. **文献研究法**——梳理发音评价、语音特征、轻量模型、电子纸驱动与间隔复习的已有工作。
2. **实验法**——通过语音采集、模型训练、单片机部署与硬件测量获得实验数据。
3. **对照法**——相同样本与测试条件下比较规则法与模型法，并比较量化前后的体积、准确率与耗时。

## 六、硬件与软件环境

**硬件（拟选型，最终以实物为准）**

- 主控：ESP32-S3（带 PSRAM，支持向量指令，适合轻量推理）
- 显示：电子墨水屏（局部刷新，具体型号待定）
- 音频：I2S 数字麦克风 + I2S 音频功放
- 交互：按键或触摸模块
- 电源：锂电池 + 充电管理

**软件**

- 固件：ESP-IDF / Arduino-ESP32（待定）
- 训练：Python + PyTorch（或 TensorFlow），量化后导出 TFLite / ESP-DL 可用的模型
- 版本管理：Git + GitHub

## 七、数据集与标注

- 词库：不少于 50 个英语词条。
- 语音：不少于 200 条真实跟读录音，按统一标准人工标注为"发音正确"或"发音需要改进"。
- 划分：训练集 / 验证集 / 测试集，划分比例与标注规范见 `docs/` 下的数据集说明。
- 原始录音体积较大，不直接入库，通过发布附件或网盘分发；仓库内只保留标注表与处理脚本。

## 八、评价指标

| 类别 | 指标 |
|---|---|
| 分类效果 | 准确率、精确率、召回率、F1，与人工标注的一致程度 |
| 运行效率 | 单次推理耗时、模型体积（量化前后） |
| 系统功耗 | 待机 / 录音 / 推理状态电流，墨水屏刷新耗时 |
