# firmware — 设备端固件

ESP32-S3 上的全部运行代码：墨水屏驱动、音频输入输出、端侧推理、复习调度与无线同步。

## 规划结构

```
firmware/
├── main/               # 主程序、状态机、任务调度
├── components/
│   ├── display/        # 墨水屏驱动：全刷、局部刷新、残影处理
│   ├── audio_in/       # I2S 麦克风采集、端点检测（VAD）
│   ├── audio_out/      # 单词标准音播放
│   ├── infer/          # 特征提取 + 量化模型推理
│   ├── review/         # 词库与间隔重复调度
│   └── net/            # Wi-Fi 配网与学习记录同步
├── models/             # 由 ml/ 导出的 .tflite / C 数组（大文件慎入）
└── CMakeLists.txt
```

## 约定

- 分支开发，合并前保证 `idf.py build` 通过；提交信息写清影响的外设。
- 引脚定义集中在 `main/board_config.h`，不散落在各模块。
- 模型文件如超过 5 MB，改用 Release 附件或 Git LFS。
- 关键参数（采样率、帧长、特征维度）在 `docs/` 与 `ml/` 中保持一致并注明版本。
