# hardware — 硬件资料

原理图、PCB、BOM 与结构件。设计源文件与导出的可读版本一并保留。

## 规划结构

```
hardware/
├── schematic/          # 原理图（.kicad_sch 或立创EDA工程）
├── pcb/                # PCB 源文件、叠层与阻抗说明
├── bom/                # BOM 表、替代料、采购链接与单价
├── datasheets/         # 关键器件手册（墨水屏、功放、电源芯片）
├── enclosure/          # 外壳 3D 模型（step / stl）
└── test/               # 打样测试记录、飞线修改、问题清单
```

## 选型要点（拟定）

| 部分 | 方案 | 关注点 |
|---|---|---|
| 主控 | ESP32-S3 + PSRAM | 向量指令、推理内存余量 |
| 显示 | 电子墨水屏 | 局部刷新能力、残影、刷新耗时 |
| 音频输入 | I2S 数字麦克风 | 信噪比、与扬声器的声学隔离 |
| 音频输出 | I2S 功放 + 扬声器 | 音量、静态功耗 |
| 电源 | 锂电池 + 充电管理 | 待机电流、低压保护 |

## 约定

- 版本号写在丝印与 `pcb/CHANGELOG.md` 中，每次打样递增（v0.1、v0.2 …）。
- BOM 必须标注"已采购 / 待确认 / 停产替代"，避免组装时才发现缺料。
- 大体积 3D 模型可用 Git LFS 或外部网盘；本仓库优先存 step 格式。
